# Launcher-info for Lokal CRM V3.2

## Bruk
1. Legg `Start_CRM.command` i samme mappe som `app_v32_layout.py`.
2. Åpne Terminal og kjør én gang:
   ```bash
   chmod +x Start_CRM.command
   ```
3. Dobbeltklikk `Start_CRM.command`.

## Hvis macOS blokkerer filen
- Høyreklikk filen -> **Åpne**
- Eller gå til **System Settings -> Privacy & Security** og tillat kjøring.

## Feilsøking
Launcheren skriver logg til:
- `Start_CRM.log`
